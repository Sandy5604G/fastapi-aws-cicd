3. END-TO-END ARCHITECTURE & DATA FLOW
--------------------------------------------------------------------------------
1. Code Commit:
   Developer pushes code to the 'main' branch on GitHub.

2. Webhook Event:
   GitHub sends an automated HTTP POST webhook to the Jenkins server running
   on AWS EC2.

3. Jenkins Pipeline Execution:
   - Stage 1: Validate & Prepare
     Extracts Git commit SHA tag (e.g., a1faee06) and verifies environment.
   - Stage 2: Quality & Unit Testing
     Runs Ruff linter and Pytest in an isolated Docker container with an 80%
     code coverage gate (achieved 100% test coverage).
   - Stage 3: Docker Image Build
     Builds production-ready multi-stage Docker container.
   - Stage 4: Trivy Security Scan
     Scans the built container for CVE vulnerabilities. Gates the build on
     0 HIGH and 0 CRITICAL vulnerabilities.
   - Stage 5: ECR Image Push
     Logs into Amazon ECR via an attached IAM Role and pushes the immutable
     git-SHA tagged image.
   - Stage 6: Rolling Deployment to ECS Fargate
     Registers a new Task Definition revision and triggers rolling update
     with deployment circuit breaker (automatic rollback if tasks fail health).
   - Stage 7: Smoke Testing
     Queries the live ALB endpoint until the new version SHA is verified live.
